# undexeror // archive — безопасная структурная версия

Эта сборка создана из переданного `index.html` без изменения логики, дизайна, текстов или порядка CSS-правил.

## Структура

```text
undexeror_archive_refactor/
├── index.html
└── assets/
    ├── css/
    │   └── archive.css
    └── js/
        └── archive.js
```

## Что изменено

- Встроенный CSS вынесен в `assets/css/archive.css`.
- Встроенный JavaScript вынесен в `assets/js/archive.js`.
- `index.html` теперь содержит разметку и подключения ресурсов.
- JavaScript оставлен единым IIFE-файлом: его общая область видимости и порядок инициализации сохранены.
- Порядок всех CSS-правил сохранён, чтобы не менять каскад и визуальные состояния.

## Важно перед публикацией

В архив не включены медиафайлы, поскольку был передан только `index.html`. Скопируй в корень этой папки те же файлы, которые используются текущим сайтом: `bg.jpg`, локальные MP3/M4A-треки и папку `music/` (если она есть). Относительные пути к ним не менялись.

Загружай на GitHub Pages содержимое папки `undexeror_archive_refactor`, а не саму zip-папку.

## Что намеренно НЕ делалось

- Не менялись цвета, размеры, типографика, анимации и HTML-компоненты.
- Не удалялись функции.
- Не менялись API-запросы, ключи localStorage, данные профиля и адреса внешних сервисов.
- Не дробился JS на ES-модули: это отдельный этап после проверки текущего поведения.

Это базовая структурная подготовка перед визуальным редизайном и точечной оптимизацией FPS.
